## 包含內容與啟動

包含三端前端、後端 API、資料庫遷移、測試及部署說明。解壓後閱讀 `README.md`、`DEPLOYMENT.md` 和 `CLOUDFLARE_TEST_DEPLOYMENT.md`。使用 Node.js 安裝依賴，依 `.env.example` 自行設定運行環境；密鑰及真實資料須另外安全配置。

不包含 `.env`、密鑰、資料庫備份、上傳照片、員工或客戶業務資料、灰度測試結果及依賴目錄。這是源碼快照，不是業務資料備份。完整性可依同名 `.sha256` 檔案核對。
